# Contact Information Form

A clean, responsive Google Form-like contact information web form built using HTML and CSS.

## ✨ Features

- Responsive design for all screen sizes
- Validated input fields (name, email, phone, etc.)
- Radio button selection for gender
- Styled with modern CSS, minimal and professional look
